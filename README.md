Amazon VPC Lattice is an application networking service that consistently connects, monitors, and secures communications between your services, helping you to improve productivity so that your developers can focus on building features that matter to your business. It simplifies service-to-service connectivity and security across VPCs and accounts.

**Areas:** AWS · Microservices · Service Mesh · Service Networking
